# Switchboard

**Feature management for .NET** — feature flags, targeting, progressive rollouts, kill switches, and experimentation. Self-hosted and open, with no vendor lock-in.

> **Build from source.** This SDK is complete and conformance-tested; build it from the [monorepo](https://github.com/switchboard-io/switchboard).

- Website: https://switchboard.co
- Source: https://github.com/switchboard-io/switchboard
- License: Apache-2.0

## Install

```bash
dotnet add package Switchboard
```
