Why Playground GitHub

Feature flags. One engine.
Six languages. Proven identical.

Open-source, self-hosted feature management. Targeting, progressive rollouts, kill switches, and experimentation — evaluated locally in-process, with no vendor lock-in.

Try the playground Self-host on GitHub

Proven cross-language

.NET, JS, Python, Go, Java, and Rust implement one spec. A shared corpus runs through all six in CI — currently 150/150 checks passing, including exact rollout-bucket identity.

No lock-in

Portable JSON schema, OpenFeature providers everywhere, and full self-hosting. Your config lives in your repo; your data stays on your infra.

Local evaluation

SDKs evaluate in-process at 100k–1M evals/sec. The server streams updates; an outage never blocks your app.

Install

dotnet add package Switchboard.Sdk
npm install @switchboard/sdk
pip install switchboard-sdk
go get github.com/switchboard-io/switchboard-go
cargo add switchboard-sdk

Evaluate a flag (same shape everywhere)

import { SwitchboardClient } from "@switchboard/sdk";

const client = SwitchboardClient.fromJson(snapshot);
const on = client.getBool("checkout-v2", {
  key: "user-42",
  attributes: { country: "US" }
});

Run the server

docker compose up --build
# open http://localhost:8080  — Admin UI + REST + live updates
